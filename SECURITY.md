# Security policy

## Supported versions

`quiet-choir` is pre-release software and does not yet publish supported versions. Security fixes
are made on the default branch until a release policy is established.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting](https://github.com/plx/quiet-choir/security/advisories/new) flow
and include reproduction steps, impact, and any suggested mitigation.

If GitHub does not show the private reporting form, the repository setting has not been enabled yet;
contact the repository owner through an existing private channel instead. Maintainers must configure
the private intake and add response and disclosure expectations before the first public release.
